# project-frontend

Frontend application for the hospital management system.

## Stack
- React
- Vite
- Axios
- React Router

## Setup

```powershell
cd project-frontend
npm install
npm run dev
```

## Environment
Create a `.env` file based on `.env.example` and set the backend URL:

```env
VITE_API_BASE_URL=http://localhost:8080/api
```

## Notes
- Keep the frontend repo limited to UI, assets, and client-side config.
- The backend API lives in a separate repository.
